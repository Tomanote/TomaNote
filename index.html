v 0.5.3









Roadmap

ANTERIOR

0.5.2

2026-08-01

  • Recent notes preview

    The command palette now shows your 3 most recently edited notes on open, sorted by last modified time.

  • Per-tab timestamps

    Each tab tracks its last modified timestamp to sort recent notes, preserved on every save.

  • Responsive command palette footer

    The command palette footer adapts to the device — keyboard hints on desktop and tap hints on touch screens.

  • Command palette legibility

    Command palette text now uses the theme's text color with stronger font weights, readable across all themes.

ACTUAL

0.5.3

2026-08-10

  • New branding

    New logo, icons, screenshots and favicon renewed across the whole app.

  • Code block contrast

    Code blocks now use readable colors across all themes.

  • Inherited font size

    New empty tabs inherit the configured global font size.

  • Tab name editing

    The full name is shown while editing and the caret is placed at the start.

  • Plain-text paste

    Pasting into a tab name inserts plain text without formatting.

  • Undoable paste

    Pasting in the editor is now undoable and respects the cursor position.

  • Pin emoji preservation

    Alt+P keeps the tab's existing emoji when pinning.

  • Collapsed controls tooltips

    The collapsed right panel buttons now show tooltips.

  • Saved indicator

    A 'Saved' indicator appears after you pause typing.

  • Ctrl+S shortcut

    Ctrl+S shows instant save feedback.

PRÓXIMO

0.6.0

2026-0x-0x

  • Live Markdown preview

    Real-time Markdown preview using Milkdown, with WYSIWYG editing and full syntax support.

  • Stylus/pen input support

    Native integration with touch devices and stylus for tablets and phones, improving handwritten note experience.

  • LAN sync

    Note synchronization between devices on the same local network without database, using the primary device as server.

  • Offline pre-loading

    Pre-loading system when connection fails, showing friendly alerts and offering access to previous versions without data loss.

  • Service Worker Connection-recovery

    Service worker for automatic connection recovery, intelligent caching and offline mode.

  • More keyboard shortcuts

    New keyboard shortcuts using left_Alt for quick actions, integrated with the command palette.
